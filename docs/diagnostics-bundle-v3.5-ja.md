# Torima Auto v3.5 — チャット送信用の一括診断ZIP

## 送り方
1. アプリをv3.5に更新する。
2. トリマのHOMEで記録バーの「▶開始」を押して、紫ボタンのHOME診断を行う。
3. ひと通り試したらTorima Autoのアプリ画面を開く。
4. **画面最上部の「診断をまとめて共有（ZIP 1個）」だけ押す。**
5. Androidの共有画面からChatGPTなどを選び、**ZIPファイル1個**を送る。

共有ボタンを押すと実行中の自動操作を停止して結果を確定します。クラウドへの自動送信は行いません。ZIPには画面画像・操作履歴が含まれるため、共有先を確認してください。

## ZIP内の重要ファイル
- **00_HOME_診断結果.txt**: HOMEから先に進めた方法と根拠、全試行の結果が最初に読める。
- **01_HOME_試行詳細.json**: 1回ごとの入力方式、座標、送信結果、アプリクリックイベント、画面遷移の証拠。
- **02_操作履歴.json**: 従来の自動操作ログ。件数上限で古いHOME操作が消える場合があるため、HOME結果は別記録。
- **03_回収タスク履歴.json**: 残回数の観測、タスク終了状態。
- **04_画面ノード記録.txt**: ユーザーが収集した画面のUIノード。
- **05_学習済み操作.txt**: 画面・操作位置の学習済み情報。
- **screenshots/index.json** と **screenshots/screen_*.jpg**: 実際に保存できたHOME操作前後・広告のスクリーンショット（最新24枚）。
- **manifest.json** と **README_まず読む.txt**: 診断ZIPの説明と保存数。

## HOMEの成功判定
HOMEから進んだことと、広告視聴・マイル獲得は別。

- `AD_OPEN_CONFIRMED`: HOMEを離れ、広告のSDK構造や学習済みの明確な広告操作を確認できた。**広告画面への遷移を確認**。
- `NEXT_SCREEN_CONFIRMED`: HOMEを離れ、再チャレンジやスキップ券など独立して識別できる次画面へ進んだ。**画面遷移を確認**（広告自体の判定とは別）。
- `REWARD_DECREASED`: HOMEの「あとN回」が減ったことを確認。**回数減少の証拠**。
- `UNVERIFIED_CHANGE`: UNKNOWNや表示だけ変わった画面。成功扱いしない。
- `NO_NAVIGATION`: 試行後もHOMEと確認できた。
- `SENT_UNCONFIRMED` / `INTERRUPTED`: タップ要求やGesture callbackだけで、実際の遷移証拠がない。
- `ABORTED`: タップ前に画面や対象座標が変化し、中止。

情報は操作前後の画像・画面ノード・タップ結果を基に記録されるが、Androidから取得できない広告の内部状態まで証明するものではない。

## 安全性・操作制限
トリマ以外の画面のタップは実行せず、共有ボタンはデータ収集ではなく手動共有のみ。HOMEの7方式試行・広告後ガチャ読み込み4秒保護・「友達にシェア」非タップの既存仕様は維持。
