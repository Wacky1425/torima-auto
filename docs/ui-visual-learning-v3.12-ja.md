# Torima Auto v3.12 — 3ボタン操作バーと実動作する画像学習

## 操作バー
通常は「▶ 開始」「■ 停止」「✦ 学習」、短い状態表示と「詳細・診断」のみ。
詳細を閉じている間は記録、画像、指比較、従来の登録などを表示しない。
見出し・ボタン・状態表示を長押ししてドラッグ可能。誤タップ防止にドラッグ後は短時間クリックを無効化。
長押しの移動は操作バーのみで、トリマ画面全体を長押しして動かす機能ではない。

## 学習方式（1回で自動登録）
1. 操作を止めて「学習」を選び、広告の×／スキップの位置を1回タップする。
2. AndroidのUIツリーに識別可能な一意のノードがあれば、既存のノード操作ルールとして登録。画像が必要ない。
3. ノードがない、候補が複数、名前・IDがない場合は、画面に「ノードがない」「候補が○件」「ノードはあるがボタン特定不可」を表示して画像学習へ自動切替。
4. 画像学習はオーバーレイを一時的に隠し、**タップ前のスクリーンショット**からタップ座標近くの局所15×15と周囲11×11のグレースケール特徴を保存する。フルスクリーンの完全一致ではない。数十pxの表示位置差や一部の広告画像の変化を許容する。
5. 1回の操作後にノード／画像ルールを自動保存する。二度目の「登録」は不要。失敗時は理由を表示して登録を増やさない。新しい未採用例は今後蓄積しない。
6. 過去の未採用学習例は自動削除しない。アプリの「古い保留例だけ削除」から削除可能。ノード／画像の有効な学習ルールは残す。
7. 端末に保存するのは小さな数値テンプレートと相対座標。学習画像をサーバーへ送信しない。

## 自動使用
1. トリマ内で動画広告の開始経路を確認した後、既存のノード照合に加えて画像テンプレートを解析する。
2. **画像を連続2回**取得し、学習済みの局所・周囲の両方が十分一致した場合のみ、ユーザーが示した位置の近くをタップする。複数候補が僅差なら操作しない。
3. HOME、報酬、ガチャカード、シェア、スキップ券使用画面の固有判定が優先。
4. Google Playの商品ページを開くようなインストール・購入・共有操作は学習しない。
5. 古いスクリーンショットを持っているだけでは操作しない。画面をライブで判定する。

## 注意
- 全種類の広告・Androidバージョンで動作確認できたものではない。
- ノードが取得できず、画面画像の特徴が少ない場合は自動登録に失敗する。失敗理由が表示され、意味のない保留例は増えない。
- 画像に非常に似た別画面が表示されると誤認の可能性があり、動画広告への遷移、対象領域、ガチャ状態、2フレームの一致を合わせて判定する。
- 過去に有効化した高速実験モードの設定は維持。広告直後の保護を外す設定にはガチャの誤キャンセルリスクがある。

## 診断
従来どおり診断ZIP1つを共有すれば、ノード操作ルールと新規画像ルール、各種診断情報を確認できる。
