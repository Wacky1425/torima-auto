# Torima Auto v3.6 — HOMEの「指」と「自動」を比較

HOMEの紫ボタンが自動では進まないのに指では進む現象を調べる診断用アップデートです。v3.5のHOME 7方式の自動試行はそのままに、指によるHOMEタップの観測モードを追加します。

## 手順（1回の診断）

1. v3.6に更新する
2. トリマのHOME画面で操作バーの「▶開始」を押し、自動タップを試す
3. 自動試行が終わってもHOMEのままであれば、同じ操作バーの「指で押す比較（18秒）」を押す
4. 「画像取得中」のあと「指で押してね」と表示されたら、HOMEの紫ボタンを指で1回だけ押す。他のボタンを押さず18秒ほど待つ
5. Torima Autoのアプリ画面を開き、「診断をまとめて共有（ZIP 1個）」を押す
6. 生成されたZIPだけをChatGPTに送る

## 診断ZIP

- 00_指タップと自動の比較.txt : 最初に読む比較結果。自動7方式と指の結果、CLICK通知、画面変化や広告表示までの時刻
- 06_指タップ比較イベント.json : 指タップ観測時のUI状態・ノード数・大きなクリック対象・クリックイベント・画面遷移の経過時間
- 00_HOME_診断結果.txt / 01_HOME_試行詳細.json : v3.5からある自動方式の詳細。新しい指モードはこれを上書きしない
- その他の操作履歴、回収ログ、学習済みルール、前後のJPEGなども同じZIPに同梱

## 何が分かるか

- 指と自動で、TYPE_VIEW_CLICKEDが同じように発生したか
- クリック対象のAccessibilityクラス・View ID・矩形は一致するか
- HOMEのUI状態（残り回数、選択されたmove、ボタン状態）の違い
- 画面を離れたか、明確な広告表示に遷移したか、時間差はどれくらいか
- 自動のジェスチャー完了、クリック通知、広告画面遷移の3事実が異なること

**取得できないもの** : 他アプリに実際に配送された指の生MotionEvent、圧力・面積、OSが付ける内部フラグ、アプリや広告SDK内部の処理・通信。Accessibilityだけで「なぜ指だけ受理されるか」を必ず断定できるわけではありません。

## 安全性

- 指タップモードは操作を観測するだけで、アプリ画面にタップを送らない
- 18秒間だけTorima Autoのフローティング操作バーをタッチ透過し、自動で復帰
- 自動操作とは同時実行しない
- ZIPは手動共有されるまで端末内に保存され、勝手に送信しない
- v3.5の広告終了後4秒の誤ガチャキャンセル防止は変更しない
