v0.5 UIツリー診断版

目的:
トリマの各画面で AccessibilityNodeInfo から何の文字・ボタン・座標が取得できるか確認する。

使い方:
1. アクセシビリティサービスをON
2. 「5秒後にPowl UIを読み取る」
3. 5秒以内に調べたいPowl画面へ戻る
4. 5秒後に現在のアクティブウィンドウを読み取る
5. テストアプリへ戻る
6. 「取得結果」に text / contentDescription / clickable / bounds が表示される

まずHOMEで試す。
結果に「動画を見て」等が出れば、その画面は画像認識よりUIツリーを優先できる。
この版はUI読取のみ。自動タップ・自動ループは行わない。
